# mini-omnichord-app

コード選択と4つのタッチ電極で弾く、オムニコード風のWeb楽器です。

index.html、style.css、main.jsを同じフォルダーに置き、index.htmlをブラウザで開きます。コードボタンをクリック／タップすると、そのコードを選択してS1の音を1回鳴らします。選択中のボタンも再タップできます。

MIDI入力は自動で検出し、RV003USB Example MIDI Deviceを優先します。見つからない場合は利用できる入力を1台選びます。選択された機器名は「入力MIDIデバイス：」の後に表示します。ブラウザからMIDIアクセスの許可を求められた場合は許可してください。最初にコードボタンを押すと音声が有効になります。MIDI入力にはWeb MIDIに対応するブラウザと、HTTPSまたはlocalhostなどブラウザが許可する環境が必要です。実機での接続確認は未実施です。

入力番号はS1=48、S2=52、S3=55、S4=60。実機と異なる場合はmain.jsのINPUT_NOTESを変更してください。全MIDIチャンネルを受信します。

キーC/F/G/Amごとに4コードを選択します。各コードの4音は `main.js` の `CHORD_MAP` に定義しています。

Note Offとベロシティ0のNote Onは無視します。初期音色は三角波による約2.2秒の自然減衰音。ベロシティを音量に反映し、連打は最大32音まで重ねます。これらの音色設定は暫定です。

コード変更時は以前の音を維持します。キー変更時は全音停止とコード選択解除。MIDI切断時も全音停止します。起動時はキーC・コードCです。コード未選択時はMIDI入力で発音しません。
